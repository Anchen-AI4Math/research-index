## 如何理解进展

研究阶段与验证状态分开记录：

| 维度 | 可用状态 |
| --- | --- |
| 研究阶段 | 探索中、证明中、形式化中、成果归档、暂停 |
| 验证状态 | 实验观察、纸面论证、Lean 检查、独立复验 |
| 发表状态 | 未投稿、已投稿、评审中、已发表 |

只有明确的证据才能支持相应状态。平台接受记录、Lean 构建和论文发表分别注明来源；不从课题名称推断完成情况。本次整理仅核对公开导航与路径，没有重新运行各课题证明。

## 维护方法

默认 agent 收尾维护流程见 [MAINTENANCE.md](MAINTENANCE.md)。该流程维护组织主页与本目录，不更新个人主页。

1. 新建独立课题仓库时，在上方仓库表添加一行，链接到其 README 和验证记录。
2. 共享工作区新增课题时，更新工作区 `missions/index.json`，并同步本目录的课题表与 [catalog.json](catalog.json)。
3. 每个课题在自己的仓库维护状态、下一步工作和证据；总目录保持导航简洁。
4. 仓库迁移后更新入口链接；暂停的课题保留入口并在源状态文档注明。

建议相关仓库使用 `ai4math`，并按实际内容添加 `lean4`、`formal-verification`、`number-theory` 或 `algorithms` 等 Topics。
